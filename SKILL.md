# Alpha research and deployment skill

## Trigger

Use this workflow when evaluating, improving, documenting, or deploying Vaiśravaṇa Alpha.

## Workflow

1. Capture Git, Docker, Telegram, and SQLite baseline.
2. Read persistent trade data and reconcile fees.
3. Review code path from market data to entry, exit, wallet, storage, and Telegram.
4. Make a focused reversible change.
5. Run syntax, tests, Docker build, and database integrity checks.
6. Deploy paper mode while preserving the volume.
7. Verify health, heartbeats, Telegram commands, and report outputs.
8. Record the experiment and commit only reviewed files.

## Strategy principles

Aggressive participation is required. Improve profitability through better expected edge, cost accounting, relative value, sizing, and execution quality rather than indiscriminate trade suppression. Counter-trade is a directional hypothesis, not automatically arbitrage.

## Verification

A successful deployment requires a healthy container, advancing feed/database activity, correct persistent Telegram performance, and no repeated runtime errors.
